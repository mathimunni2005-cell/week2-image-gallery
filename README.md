# Week 2 — Interactive Image Gallery

This project completes the Week 2 option: **Interactive Image Gallery**.

## Assignment requirements covered
- Displays 8 images in a responsive grid.
- Clicking an image opens a larger lightbox view.
- Hover animations scale and brighten the images.
- JavaScript DOM manipulation and event listeners handle the interactions.
- Close with the X button, outside click, or Escape key.
- Previous/next buttons and keyboard arrow keys navigate the gallery.

## Files
- `index.html` — semantic HTML layout and gallery content
- `style.css` — responsive grid, hover animation, and lightbox styling
- `script.js` — click events, lightbox controls, and keyboard handling

## Run locally
Keep all three files in the same folder and open `index.html` in a browser. An internet connection is required for the remote Unsplash images and Google Fonts.

## Publish on GitHub Pages
1. Create a public repository, for example `week2-image-gallery`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait until GitHub Pages displays the published website URL.

For the assignment submission, use a real HTTPS URL from your GitHub repository or published GitHub Pages site. The repository URL is `https://github.com/YOUR-USERNAME/week2-image-gallery` after you create it; replace `YOUR-USERNAME` with your GitHub username.
